# v3.68.0 发布说明 — 小版本：DBC 字节位图 + NM 唤醒原因时间线

**发布日期:** 2026-11-26

## 概览

本版交付两个用户可见功能：

1. **DBC 字节位图** — 选中消息即可看到信号在经典 CAN 8 字节 / CAN FD 64 字节载荷里的位分布，并以 33ms 节流实时点亮当前消息。
2. **NM 唤醒原因时间线 + 静默相位推断** — 把唤醒/保持唤醒原因的原始值翻成可读时间线；对静默空档按 NM 超时、发送者归属与应用报文活动推断释放等待 / 准备休眠 / 睡眠相位。

## 新功能

### DBC 字节位图（静态 + 实时）

- 选中消息行即渲染载荷位图：Intel（LSB0）/ Motorola（MSB0）与 `SignalDecoder` 逐行同构；渲染列固定 bit 7 → bit 0。
- 多路复用：下拉切换分支，复用器始终绘制；重叠按声明顺序后者覆盖，格与信号表标注重叠。
- 异常输入全部可见标注、不抛异常：`Length=0`、`Length>64`、部分/全部越界、`DLC>64`（只渲染 64 字节并警告）。
- 实时点亮（二期）：仅当前选中消息走 33ms 节流；0 位变淡、信号表新增“当前值”列；帧内 mux 与选中分支不符时 muxed 信号显示“—”而不是错误数值；短帧缺失字节不按 0 解码；切到其他标签页自动停表，切回立即恢复。
- 性能守卫：快照计算中位数 ≤5ms；首次投影（含实时投影一遍）中位数 ≤30ms，不含 WPF 实际渲染。

### NM 唤醒原因时间线 + 静默相位推断

- 原因字典 `*.nmreasons.json` 由 `nmprofile.json` 的新增可选字段 `reasons_path` 显式引用，不按文件名自动发现；逐帧解码声明字段，DBC 值表精确命中显示文字，否则明确写“含义未配置”。
- 与现有 NM 时间条共用 X 轴的原因行；事件表新增 `reason_change` 行，可单击跳转原始报文；Markdown 报告与 CSV 导出增加原因段（原始值、解释来源、报文时间、完整性标记）。
- 无字典 / 字段不可读 / 窗口截断 / 跨 episode 时明确降级，不推断。
- 静默相位：对每个候选空档按 NM 超时边界 + 发送者归属 + 应用报文活动推断 `release_wait` / `prepare_sleep` / `sleep`，NM 面板“整网状态”行分色显示，hover 给出帧数、发送者、最大总线空档与依据；导出与 AI overview 同步。相位只进结构化数据与 observation，不产生 finding，也不声称任何节点“已睡眠”。

## 验证

- DBC 字节位图：Core `SignalBitLayout` 定向 21 / 0；App 七类定向 87 / 0；构建 0 error / 0 warning。
- NM 部分为既有提交 `3fe937d7` 的功能，本轮未重跑其定向测试。
- 未跑全量测试；`peakcan-hil-core` 无改动；无新增 NuGet 依赖。
- 人工 WPF 验收未执行：位图的 FD 展开手感、切页恢复、mockup 视觉对拍仍需人工确认；启动冒烟不能替代渲染验收。

## 兼容性

- host 仍依赖 **PeakCan.HIL.Core 0.23.1**，`Directory.Packages.props` 未变。
- `nmprofile.json` 只新增可选 `reasons_path`；旧 profile（无该字段）行为不变。
- 未发现 breaking API 变更；DBC 位图只新增 UI 与只读数据投影。

## 已知限制

- DBC 位图：FD 512 格统一多行渲染，不做额外压缩/滚动增强；全消息逐帧染色不在本版范围。
- NM 原因时间线：第一版不做位掩码逐位展开、不做 AI 归因、不做因果结论；字典需用文本编辑器维护。
- NM 静默相位是推断而非判定：不声称节点已休眠，不产生 finding。
